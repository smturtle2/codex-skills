## 설치

```text
Use $skill-installer to install skills/gomoku from https://github.com/smturtle2/codex-skills.
```

데스크톱 GUI 환경, Python 3.11 이상, Pygame이 필요하며 런처는 uv로 Python 의존성을 관리합니다. 상대의 수는 Codex가 결정합니다.

## 사용 예시

```text
$gomoku로 오목을 시작해줘. 15×15 보드에서 내가 흑으로 둘게.
```

## 작업 파일

위치를 지정하지 않았다면 재개 가능한 게임 상태를 프로젝트 루트 기준 `.codex-skills/gomoku/<run-id>/`에 보관합니다. 사용자가 위치를 지정하면 그 위치를 우선하고, 기존 상태는 옮기지 않고 그 자리에서 재개합니다. 재개에 필요한 데이터는 보존하고 이번 실행에서 만든 폐기 가능한 중간 파일만 정리합니다.

보드를 닫으면 연결된 대기가 끝나고 게임은 보존됩니다. 같은 작업 폴더로 다시 열면 이어서 플레이합니다. 초기화는 새 게임 식별자를 만들며, Codex는 착수할 때 현재 뷰의 게임 식별자와 리비전을 함께 전달합니다. 오래된 선택은 초기화되거나 변경된 보드를 수정할 수 없습니다. GUI와 CLI는 같은 잠금과 원자적 저장 절차로 상태를 갱신합니다.

## 결과물

착수 검증, 승리 판정, 선택 가능한 렌주 제한을 갖춘 Pygame 보드. 렌주에서는 새 돌을 공유하는 서로 다른 사와 합법적으로 활사로 확장할 수 있는 삼을 판정하며, 확장 수가 다시 금수인지도 재귀적으로 확인합니다. 동시에 만들어진 정확한 오연은 다른 금수 모양보다 우선합니다. 백과 일반 오목에서는 오연 이상으로 승리합니다. 공개 전술 뷰는 착수 검증과 같은 규칙 판정기를 사용하고, 수를 선택하거나 점수를 매기지 않습니다. 초반 착수와 보드 설정은 자유롭게 선택합니다.
