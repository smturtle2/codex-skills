# ui-blueprint

Generate a visual blueprint, read its design decisions, then implement the screen in the existing frontend stack.

[All skills](../../README.md#skills) · [한국어](ui-blueprint.ko.md)

<a id="install"></a>

## Install

```text
Use $skill-installer to install skills/image-creator and skills/ui-blueprint from https://github.com/smturtle2/codex-skills.
```

Install `image-creator` too. Designed for new screens and substantial redesigns.

## Example

```text
Use $ui-blueprint to redesign the reading dashboard in this app. Show current books, reading progress, and recent notes.
```

## Working files

Store the generated working preview and review notes in the project-root-relative `.codex-skills/ui-blueprint/<run-id>/` workspace. An explicit work location wins, and older existing locations are resumed in place. Retain resumable data and remove only expendable intermediates created by this run. Preserve the mockup at the user-requested delivery destination.

## Output

A retained working mockup, an implemented screen, and desktop/mobile visual verification. When a delivered mockup is requested, it is also saved at that destination.
