# ui-blueprint

시각적 시안을 생성하고 디자인 결정을 정리한 뒤, 기존 프런트엔드 스택으로 화면을 구현합니다.

[스킬 목록](../../README.ko.md#skills) · [English](ui-blueprint.md)

<a id="install"></a>

## 설치

```text
Use $skill-installer to install skills/image-creator and skills/ui-blueprint from https://github.com/smturtle2/codex-skills.
```

`image-creator`도 설치하세요. 새 화면 제작과 큰 폭의 개편에 적합합니다.

## 사용 예시

```text
$ui-blueprint로 이 앱의 독서 대시보드를 개편해줘. 읽는 책, 독서 진행률, 최근 메모가 보여야 해.
```

## 작업 파일

생성한 작업용 미리보기와 검토 메모는 프로젝트 루트 기준 `.codex-skills/ui-blueprint/<run-id>/`에 보관합니다. 사용자가 작업 위치를 지정하면 그 위치를 우선하고, 기존 위치는 옮기지 않고 그 자리에서 재개합니다. 재개에 필요한 데이터는 보존하고 이번 실행에서 만든 폐기 가능한 중간 파일만 정리하며, 시안은 사용자가 요청한 전달 위치에 보존합니다.

## 결과물

작업 폴더에 보존된 시안, 구현된 화면, 데스크톱·모바일 시각 검증. 시안 파일의 전달을 요청하면 지정한 목적지에도 저장합니다.
