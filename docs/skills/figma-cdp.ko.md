# figma-cdp

공통 CDP 도구로 실제 Figma 문서를 직접 조작해 디자인을 제작하고 다듬으며, 네이티브 편집과 실제 렌더링 결과를 활용합니다.

[스킬 목록](../../README.ko.md#skills) · [English](figma-cdp.md)

<a id="install"></a>

## 설치

```text
Use $skill-installer to install skills/figma-cdp from https://github.com/smturtle2/codex-skills.
```

## 요구 사항

호스트에서 `Runtime.evaluate`를 지원하는 기존 브라우저 CDP 연결과 설치된 보조 모듈을 불러올 수 있는 JavaScript 실행 환경을 제공해야 합니다. 해당 브라우저에서 요청한 Figma 파일에 접근할 수 있고, 의도한 편집 권한과 실제 `window.figma` API가 있어야 합니다. 연결과 API 접근은 실제 환경에서 확인하며, 한 환경의 성공이 모든 브라우저나 Figma 환경의 지원을 의미하지는 않습니다.

포함된 모듈에는 패키지 의존성이 없습니다. 호스트의 브라우저 연결을 사용하며, 별도 연결을 만들거나 브라우저 확장 프로그램·MCP 서버를 설치하지 않습니다.

## Figma에서 작업하기

에이전트가 공통 도구를 사용해 실제 Figma 문서에서 결과물을 만들고 다듬습니다. 확정된 디자인 판단을 실행하는 조작은 함께 수행합니다. 다음 디자인 판단이 문서 구조나 시각적 결과에 달려 있으면 관련 결과를 조회하거나 렌더링하고 그 근거로 결정합니다.

주 인터페이스는 네 도구로 구성됩니다.

| 도구 | 책임 |
| --- | --- |
| `inspect` | 문서 구조·속성·텍스트 구간·리소스·폰트·편집기 상태·지원 동작 조회 |
| `edit` | 노드·구조·텍스트·컴포넌트·리소스·프로토타입 반응의 명시된 변경 적용 |
| `view` | 현재 페이지·선택·화면 위치와 배율 변경 |
| `export` | 형식별 설정에 따른 네이티브 출력과 결과 유형 반환 |

`run`은 예비 전용입니다. 필요한 네이티브 기능을 주 도구로 수행할 수 없을 때만 사용하며, 주 도구가 이미 지원하는 조작을 우회하거나 대체하는 데 사용하지 않습니다.

공통 구현이 네이티브 참조 해석, 폰트 준비, 복합 동작의 실행 순서와 결과 보고를 맡습니다. 에이전트는 디자인을 판단하고 반환된 관측 자료를 호스트에서 분석합니다. 지원 기능 조회는 구현된 계약과 네이티브 API 가용성을 구분하며, API가 있다는 사실만으로 대상·권한·폰트·라이브러리·요금제에서 해당 동작이 허용된다는 의미는 아닙니다.

범위가 제한된 조회는 이어 읽기를 제공하고, 복제는 하위 요소의 조건부 대응 정보를 보존합니다. 순서가 있는 편집 묶음은 실제 식별자를 사용하고 항목별 결과를 보고합니다. 선택적 조회와 출력은 편집 결과 확인 후 같은 주 도구를 재사용합니다. 실패하면 확인된 진행 상태와 불확실성을 보고하며, 결과가 불확실한 편집을 자동으로 재실행하지 않습니다. 예비 실행에도 같은 연결·불확실성 처리를 적용하고, 쓰기가 일어날 수 있는 실행으로 보수적으로 취급합니다.

부모를 생략한 화면 요소·인스턴스 생성은 요청 실행 시작 시점에 확정한 페이지를 사용합니다. 명시한 식별자를 대상으로 하는 문서 편집은 사용자가 다른 페이지를 보더라도 그 대상을 유지합니다. `view`는 예상하지 못한 페이지 변경을 감지하면 중단합니다.

브라우저 연결·복구 제어, 파일 생성·이름 변경, 프레젠테이션 조작, 브라우저 스크린샷, 결과 파일 저장과 분석은 호스트가 맡습니다. 보조 도구는 브라우저에서 신뢰하는 공통 실행 코드를 사용하며, 브라우저가 호스트 파일 시스템의 모듈을 직접 불러온다고 가정하지 않습니다.

Figma 기능의 이해와 활용은 [공식 기능 문서](https://help.figma.com/hc/en-us/categories/360002042553-Figma-design)를 참고합니다. 스킬의 [세션과 도구 계약](../../skills/figma-cdp/references/cdp-session.md)은 연결 준비·복구, 페이지 처리와 보조 도구의 동작 계약을 정의합니다.

## 작업 파일

로컬 파일이 필요할 때 기본 위치는 프로젝트 루트 기준 `.codex-skills/figma-cdp/{run-id}/`입니다. 요청한 위치가 있으면 우선합니다. 새 작업에는 고유한 폴더를 사용하고, 이전 위치를 포함한 기존 작업은 원래 경로에서 이어갑니다. 재개에 필요한 자료를 보존하고 이번 실행에서 만든 폐기 가능한 중간 파일만 정리합니다. 의도적으로 버전 관리하는 경우가 아니라면 Git에서 `/.codex-skills/`를 무시합니다.

## 결과물

제작한 Figma 문서와 관련 파일·노드 링크, 요청한 내보내기 파일을 제공합니다. Figma를 수정한 뒤 또는 승인을 요청할 때에는 브라우저 스크린샷 대신 `tool.export` 렌더를 저장하고 답변에 직접 표시합니다.

완료 전에 실제 구성과 네이티브 편집 가능성을 요청한 결과에 비추어 평가하고 중요한 문제를 해결합니다. 링크, 반환된 상태, 이미지 미리보기는 평가를 돕지만, 이것들이 있다는 사실만으로 완성도가 입증되지는 않습니다. 저장한 렌더링과 작업 기록은 후속 작업에 활용할 수 있으며, 중요한 한계가 있으면 결과와 함께 보고합니다.
