# subtitle-translator

영어 자막을 맥락에 맞게 자연스럽게 번역하고, 읽기 좋은 문장 분할과 확보한 음성 근거에 맞춰 표시 시간을 다듬습니다.

[스킬 목록](../../README.ko.md#skills) · [English](subtitle-translator.md)

## 설치

```text
Use $skill-installer to install skills/subtitle-translator from https://github.com/smturtle2/codex-skills.
```

## 요구 사항

기본 번역 흐름에는 모델과 추론 강도를 지정해 서브에이전트를 실행할 수 있는 호스트가 필요합니다. 작업을 위임할 때 해당 호스트에서 사용할 수 있는 최신 Terra와 추론 강도 `max`를 선택합니다. 요청한 기능을 사용할 수 없으면 그 상태를 보고합니다. 자막 보조 도구는 uv와 Python 3.11 이상을 사용합니다.

영어 SRT 또는 WebVTT 자막과 번역할 언어를 지정합니다. 번역할 언어를 생략하면 사용자의 언어를 사용합니다. 자막에 대응하는 영상이나 음성이 있으면 발화 시점과 불명확한 대사를 확인하는 근거로 활용합니다. 자동 생성 자막에서 의미가 불명확한 부분은 기존 환경에서 실행 가능한 로컬 음성 인식 모델로 해당 구간을 확인하며, 지원되는 GPU 실행을 사용할 수 있으면 GPU로, 그렇지 않으면 CPU로 처리합니다.

## 사용 예시

```text
$subtitle-translator로 episode.en.srt를 한국어로 번역해 episode.ko.srt에 저장해줘.
영어 자막은 자동 생성됐어. episode.mp4를 참고해서 불명확한 대사를 확인하고 타이밍도 다듬어.
```

메인 에이전트가 용어와 말투를 관리하고, 흐름이 이어지는 구간을 앞뒤 문맥과 함께 번역 서브에이전트에 전달합니다. 서브에이전트는 대사를 해석해 자연스럽게 번역하고 자막을 나누며, 추가 근거가 필요한 부분을 표시합니다. 메인 에이전트는 필요한 근거를 확보하고 구간 연결부와 공통 결정을 검토합니다.

원래 자막과 추가 음성 인식 결과는 앞뒤 대사와 함께 해석하는 참고 자료입니다. 음악·효과음·상황 설명 등 비대사 표기는 제거하고 실제 대사는 보존합니다. 번역된 대사와 읽는 호흡에 맞춰 원래 자막 칸을 합치거나 나눌 수 있습니다.

음성 인식은 발화 내용을 확인하는 데 활용하며, 타이밍에는 사용 가능한 단어별 시간 정보·정렬 결과·해당 음성 구간의 확인도 활용합니다. 자막만 있으면 원래 시간 정보를 바탕으로 작업하고 동기화를 확인한 범위를 보고합니다. 끝까지 남은 중요한 불확실성은 최종 자막 본문과 별도로 보고합니다.

## 작업 파일

작업 파일의 기본 위치는 프로젝트 루트 기준 `.codex-skills/subtitle-translator/<run-id>/`입니다. 새 번역은 고유한 폴더를 사용하고, 사용자가 작업 위치를 지정하면 그 위치를 우선하며, 이어가는 작업은 오래된 위치도 원래 경로에서 재개합니다. 작업 데이터를 의도적으로 버전 관리하는 경우가 아니라면 Git에서 `/.codex-skills/`를 무시합니다.

새 작업에서는 보조 도구의 `inspect` 명령으로 비어 있는 작업 폴더에 `source.json`과 `work.json`을 만듭니다. 이어가는 작업에서는 기존 파일과 저장된 결정을 읽고 `work.json`을 수정한 뒤 `check`로 남은 작업을 확인합니다. 원문 참조·완료된 번역·복구에 필요한 데이터는 보존하고, 이번 실행에서 만든 폐기 가능한 중간 파일만 정리합니다. 최종 자막은 원본과 별도로 요청한 목적지에 저장합니다.

## 결과물

번역문을 담은 새 SRT 또는 WebVTT 파일, 재개 가능한 작업 파일, 실제 출력 경로·음성 인식 사용 범위·타이밍 확인 근거·남은 불확실성을 정리한 보고를 제공합니다. 원문의 서식과 위치 정보는 작업 참고 자료로 보존하며, 보조 도구는 결정한 줄바꿈과 시간을 적용한 일반 자막 텍스트를 출력합니다.

보조 도구는 데이터 구조·원문 처리 상태·시간 값·저장된 출력과 현재 작업의 일치를 확인합니다. 번역 품질과 음성 동기화는 실제 내용과 확보한 미디어 근거로 평가합니다.
