```text
Use $skill-installer to install skills/idea-scribe from https://github.com/smturtle2/codex-skills.
```

## 사용 예시

```text
$idea-scribe로 동네 독서 모임 아이디어를 정리해줘. 내가 계속 말할 테니 끼어들지 말고 기록해.
```
