# subtitle-creator

영상·음성과 기존 자막을 근거로 자연스러운 자막을 만들고, 읽기 좋은 문장 분할과 확보한 음성 근거에 맞춰 표시 시간을 다듬습니다.

Use $skill-installer to install skills/subtitle-creator from https://github.com/smturtle2/codex-skills.

## 요구 사항

모델과 추론 강도를 지정해 서브에이전트를 실행할 수 있는 호스트가 필요합니다. 의미를 해석하고 자막을 구성하는 워커는 작업 위임 시 해당 호스트에서 사용할 수 있는 최신 Terra와 추론 강도 `max`를 기본으로 선택합니다. 자막 보조 도구는 uv와 Python 3.11 이상을 사용합니다.

미디어, 기존 SRT·WebVTT 자막, 또는 둘 모두와 원하는 자막 언어를 지정합니다. 언어를 생략하면 사용자의 언어를 사용하며, 원어를 요청하면 원어 자막을 만듭니다. 기존 자막이 없는 미디어는 실행 가능한 로컬 음성 인식 도구와 기존 모델 데이터로 시간 정보가 있는 발화 자료를 먼저 확보합니다. 지원되는 GPU 실행을 사용할 수 있으면 GPU로, 그렇지 않으면 CPU로 처리하고, 필요한 기능을 사용할 수 없으면 그 상태를 보고합니다.

## 사용 예시

```text
$subtitle-creator로 episode.mp4의 자연스러운 한국어 자막을 만들어 episode.ko.srt에 저장해줘.
기존 자막은 없어.
```

기존 자막이 있으면 그 자료로 시작할 수 있습니다.

```text
$subtitle-creator로 episode.mp4와 episode.en.vtt를 참고해서 한국어 자막을 만들어줘.
영어 자막은 자동 생성됐어.
```

## 자막 제작

기존 자막은 이미 시간 정보가 있는 텍스트를 제공합니다. 자막이 없으면 요청한 미디어 범위를 먼저 음성 인식합니다. 이후에는 같은 흐름에서 문맥 해석·번역, 비대사 설명 정리, 자연스러운 자막 분할, 타이밍 조정, 검토와 출력을 수행합니다.

메인 에이전트가 음성 근거를 확보하고 공통 용어와 말투를 관리하며, 흐름이 이어지는 구간을 앞뒤 문맥과 함께 분배하고 최종 결과를 검토합니다. Terra 워커는 자막을 구성하고 불확실한 부분을 표시합니다. 추가 인식은 그 구간에 집중하고 유효한 기존 작업은 유지합니다.

원래 자막과 음성 인식 결과는 주변 대사와 확보한 음성을 함께 살펴 해석하는 관찰 자료입니다. 음악·효과음·상황 설명 등 비대사 표기는 제거하고 실제 대사는 보존합니다. 목표 언어와 발화의 호흡에 맞춰 원래 자막 칸을 합치거나 나눌 수 있습니다.

전체 음성 인식은 요청 범위·처리 완료 범위·미해결 범위와 관련 결과 파일을 기록하므로, 중단되면 미완료 부분부터 이어갈 수 있습니다. 모든 범위를 처리했다는 사실만으로 모든 발화가 인식됐다고 판단하지는 않습니다. 인식 결과가 비어 있으면 확보한 음성 근거를 검토한 뒤 빈 자막을 받아들입니다.

타이밍에는 사용 가능한 단어별 시간 정보, 정렬 결과, 대응하는 음성·영상 확인을 활용합니다. 기존 자막만 있으면 그 시간 정보를 바탕으로 작업하고 동기화를 확인한 범위를 보고합니다. 끝까지 남은 중요한 의미의 불확실성과 근거의 한계는 최종 자막 본문과 별도로 보고합니다.

## 작업 파일

작업 파일의 기본 위치는 프로젝트 루트 기준 `.codex-skills/subtitle-creator/<run-id>/`입니다. 새 작업에는 고유한 폴더를 사용하고, 사용자가 위치를 지정하면 그 위치를 우선합니다. 이전 스킬 이름으로 만든 작업을 포함해 기존 작업은 원래 경로에서 재개합니다. 작업 데이터를 의도적으로 버전 관리하는 경우가 아니라면 Git에서 `/.codex-skills/`를 무시합니다.

보조 도구는 확보한 시간 정보가 있는 발화 자료로 공통 원문·작업 데이터를 만듭니다. 이어가는 작업에서는 저장된 원문, 작업 데이터, 인식 기록과 결정을 읽고 완료된 구간과 복구에 필요한 자료를 보존합니다. 이번 실행에서 만든 폐기 가능한 중간 파일만 정리합니다.

## 결과물

결정한 자막 문구·줄바꿈·시간을 담은 새 SRT 또는 WebVTT 파일, 재개 가능한 작업 데이터, 실제 저장 경로·처리 범위·음성 인식 사용 내역·타이밍 확인 근거·남은 한계를 정리한 보고를 제공합니다. 최종 자막은 모든 입력 파일과 별도로 저장합니다. 출력 형식을 지정하지 않으면 미디어만 있는 경우 SRT를, 기존 자막이 있으면 그 자막의 형식을 사용합니다.

원문의 서식과 위치 정보는 작업 참고 자료로 보존하며, 보조 도구는 일반 자막 텍스트를 출력합니다. 데이터 구조·처리 범위·시간 값·최종 파일 확인은 에이전트의 내용 검토를 지원합니다. 번역 품질과 음성 동기화는 실제 내용과 미디어 근거로 평가합니다.
